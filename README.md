# Greencharts v10

Готовая статическая версия библиотеки префлоп-диапазонов.

## Обновление на GitHub Pages
1. Откройте страницу Upload files репозитория.
2. Загрузите все шесть файлов из архива в корень репозитория, заменяя одноимённые файлы.
3. Нажмите Commit changes.
4. Обновите сайт с Ctrl+F5. В index.html добавлены параметры версии ?v=10 для принудительной загрузки новых стилей и скриптов.

В версии v10 удалены все типографические кавычки из текста фраз; приложение дополнительно очищает их непосредственно перед отображением. CSS также отключает декоративные кавычки. Покерные диапазоны оставлены без изменений.
