# Greencharts — v6

Публичная статическая библиотека preflop-диапазонов.

## Что нового
- 700 фраз: по 20 на каждую из 35 ситуаций. Это прежние 350 реплик плюс новые оригинальные шутки и конкретные комментарии к границам сохранённого baseline. Есть покерный жаргон, микролимиты, рейк, дисперсия, еда, самоирония и форумные мемы. Форумы использовались для контекста, а длинные фрагменты не копировались.
- Переключатель показывает только `ВКЛ` или `ВЫКЛ`. При `ВЫКЛ` новая реплика не выбирается, а текстовое поле остаётся пустым.
- Матрица измеряется по фактической высоте в окне браузера и сжимается только если не помещается; если помещается, сохраняет прежний размер.

## Файлы
- `index.html` — страница
- `style.css` — оформление и адаптивная матрица
- `app.js` — логика кнопок, матрицы, переключателя и подгонки по высоте
- `charts.js` — диапазоны из сохранённого `Preflop_Baseline_v1.csv`
- `phrases.js` — 700 фраз, по 20 для каждой ситуации
- `README.md` — эта инструкция

## Установка
Загрузить все шесть файлов в корень `Zeezoo777/Greencharts`, заменить файлы с совпадающими именами и нажать `Commit changes`. Настройку Pages менять не надо.

## Важно про стратегию
Диапазоны взяты из пользовательского `Preflop_Baseline_v1.csv` и представлены как категориальные действия `R` / `C` / `F`; смешанных частот здесь нет. Информационные реплики описывают конкретно эту таблицу, а не универсальную стратегию или solver-решение.
