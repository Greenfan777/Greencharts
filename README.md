# Greencharts — v8

Публичная статическая библиотека префлоп-диапазонов с компактным интерфейсом и необязательной текстовой лентой.

## Что нового в v8
- Добавлен независимый общий пул из **175 фраз**: бытовой абсурд, интернет-мемы, самоирония, еда, техника, чёрный юмор и покерная культура. Эти реплики не привязаны к выбранной позиции.
- Ситуационные фразы сохранены: иногда они дают комментарий по конкретной границе диапазона. Общий юмор выбирается примерно в 65% случаев, контекстная реплика — в 35%.
- Общий пул идёт в случайном порядке без повторов до завершения круга; фразы каждой ситуации также перемешиваются независимо.
- Переключатель показывает только `ВКЛ` / `ВЫКЛ`. При `ВЫКЛ` текст остаётся пустым и новая фраза не выбирается.
- Нежелательное английское слово убрано из метаданных и комментариев. Диапазоны рук при этом не менялись.
- Матрица автоматически уменьшается только когда не помещается по высоте окна.

## Файлы
- `index.html` — страница
- `style.css` — оформление и адаптивная матрица
- `app.js` — логика кнопок, матрицы, переключателя и фраз
- `charts.js` — сохранённые диапазоны рук
- `phrases.js` — ситуационные комментарии и общий пул фраз
- `README.md` — эта инструкция

## Установка
Загрузить все шесть файлов в корень `Zeezoo777/Greencharts`, заменить файлы с совпадающими именами и нажать `Commit changes`. Настройку Pages менять не надо.

## Точность диапазонов
Диапазоны взяты из сохранённой таблицы префлоп-диапазонов и представлены как категориальные действия `R` / `C` / `F`; смешанных частот в исходных данных нет. Информативные фразы описывают эту таблицу, а не универсальную стратегию или решение солвера.

## Текстовые фразы
Фразы отображаются без кавычек и без указания авторов. Общий пул — мемные, бытовые и покерные реплики; ситуационные фразы иногда дополнительно отмечают конкретные границы диапазона.

- В v8 удалены указания авторов и источников внутри фраз; кавычки в отображаемом тексте убраны. Покерные диапазоны не менялись.
